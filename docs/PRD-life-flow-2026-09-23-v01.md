# 기획서 (PRD): 일생의 바탕과 앞으로의 흐름을 보는 사주

> 출생 정보로 일생 전반의 성향을 살펴보고, 오늘 이후의 흐름은 원하는 미래 연도를 골라 읽는 웹서비스입니다. 이 문서는 2026-09-23 대화에서 합의한 방향이며, 세부 계산과 화면은 사용하면서 조정합니다.

작성일: 2026-09-23  
작성자: 참가자

## 1. 풀고자 하는 문제

- **현재 방식:** 서비스가 출생 정보를 받은 뒤 재직 상태와 이직 고민을 먼저 묻고, 취업 중심 카드를 보여줍니다.
- **문제점:** 사주 전반이 궁금한 사람도 특정 개인의 커리어 고민에 맞춘 질문을 따라야 합니다. 과거 생애 단계의 긴 설명은 지금 앞으로의 흐름을 알고 싶은 사용자에게 덜 유용할 수 있습니다.
- **원하는 모습:** 직업 상태와 관계없이 일생 전반의 바탕을 먼저 이해하고, 현재 시점부터 원하는 미래 연도의 흐름을 관계·일·돈 등 여러 삶의 영역에서 볼 수 있습니다.

## 2. 사용자

- **누가 쓰나요?** 사주 전반과 앞으로의 흐름이 궁금한 사람. 재직·이직 여부를 전제하지 않습니다.
- **언제 쓰나요?** 자신의 성향을 이해하거나 올해 남은 기간 또는 특정 미래 연도를 살펴보고 싶을 때.
- **어디서 쓰나요?** 컴퓨터 또는 휴대전화의 웹브라우저.

## 3. 입력 자료와 개인정보

- **필수 입력:** 양력 생년월일과 출생시간. 지금 버전의 계산 기능이 지원하는 범위를 유지합니다.
- **흐름 입력:** 처음에는 접속한 날이 속한 연도를 기본으로 보여주고, 사용자가 다른 미래 연도를 선택할 수 있습니다. 연도 허용 범위는 기능 Spec에서 정합니다.
- **선택 입력:** 더 궁금한 점에 대한 후속 질문. 특정 직업 상태나 이직 고민은 필수가 아닙니다.
- **개인정보:** 생년월일·출생시간 원문은 사주 계산에 사용하지만 Gemini에 보내거나 계정 데이터베이스에 저장하지 않습니다. 현재 저장 정책과 Google 로그인 기능을 재사용하되, 선택 연도와 새 결과 형식의 저장 방법은 구현 Spec에서 정합니다. API 키는 서버에만 둡니다.

## 4. 핵심 기능 (MVP)

1. 기존 계산 기능으로 사주 원국을 계산하고, 성향·강점·주의할 경향 등 **일생 전반의 바탕**을 쉬운 말로 보여줍니다.
2. 기본 화면에는 **올해 중 오늘 이후의 흐름**을 보여줍니다. 날짜는 2026-09-23으로 고정하지 않고 서비스 접속일을 사용합니다.
3. 사용자가 미래 연도 하나를 선택하면 해당 연도의 흐름을 다시 보여줍니다. 세 해의 상세 풀이를 한 화면에 한꺼번에 펼치지 않습니다.
4. 선택 연도의 전체 방향과 관계·일·돈 등 삶의 영역별 풀이를 함께 보여줍니다. 특정 취업 상황을 가정하지 않습니다.
5. Google 로그인 사용자는 결과를 저장하고 다시 열거나 삭제할 수 있습니다. 후속 질문 기능은 새 풀이와 모순되지 않게 조정합니다.

- **계산 기능이 할 일:** 출생 원국과 선택 연도 해석에 필요한 시간 정보를 검증 가능한 방식으로 계산합니다. 현재 코드에는 연도별 흐름 계산이 없으므로 구현 전에 계산 방식과 테스트 기준을 별도 Spec으로 정합니다.
- **AI가 할 일:** 계산된 자료를 쉬운 해석과 현실에서 확인할 조건으로 풀어씁니다. 계산되지 않은 특정 사건·시점을 지어내지 않습니다.
- **사람이 할 일:** 결과를 참고하되 관계·직업·재정상의 실제 결정은 현실 정보와 자신의 상황을 함께 확인합니다.

## 5. 결과와 완료 조건

- **결과물:** 기존 `day09` 웹 화면에 일생의 기본 풀이, 선택 연도의 흐름과 영역별 풀이를 표시합니다. 기존의 취업 고정 질문은 기본 경로에서 빠집니다.
- **정상:** 유효한 출생 정보로 기본 풀이와 올해 남은 흐름이 나타납니다. 다른 미래 연도를 고르면 해당 연도로 결과가 바뀌고, 화면에 대상 연도가 분명히 표시됩니다.
- **누락·오류:** 출생 정보가 빠졌거나 지원하지 않는 연도라면 무엇을 고쳐야 하는지 안내합니다. 연도 계산이나 Gemini 호출이 실패하면 결과를 지어내지 않습니다.
- **품질:** 풀이 근거가 실제 계산 자료와 연결되며, 미래의 사건·수익·관계 결과를 보장하지 않습니다. 저장 결과를 다시 열 때 대상 연도도 혼동되지 않아야 합니다.

## 6. 나중에 추가할 것

- 여러 미래 연도의 요약 비교 화면과 더 긴 연도 범위.
- 정확한 월별·날짜별 흐름. 해당 기간 계산과 검증을 마친 뒤 결정합니다.
- 음력 생일과 출생시간을 모르는 사용자 처리, 궁합과 타인의 사주 비교.
- 결과 공유, 만족도 기록, 결제 기능.
