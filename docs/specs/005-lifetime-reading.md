# 005 — 내 사주 전체 풀이

상태: 구현 전

## 목적

취업 상태를 묻지 않고 출생 원국을 바탕으로 삶 전반의 경향을 읽습니다.

## 동작

- 입력은 현재 계산기가 지원하는 양력 날짜와 정확한 출생시간입니다.
- `내 사주 전체`와 `앞으로의 흐름`은 같은 계산 결과를 사용합니다.
- 전체 풀이에는 한 줄 요약과 성향·강점/주의·관계·일·돈의 구분된 내용이 포함됩니다.
- 각 내용에는 계산된 원국과 연결된 근거, 현실에서 확인할 질문이 있어야 합니다.
- Gemini는 사주 계산을 다시 하거나 구체적 사건·직업·수익을 보장하지 않습니다.
- 응답 형식 검사를 통과한 결과만 보여주고 저장합니다. 실패 시 재시도할 수 있습니다.
- 기존 취업 풀이 기록을 삭제·변형하지 않습니다.

## 검증

- 유효한 출생 정보로 취업 상태 입력 없이 결과가 생성되는지 확인합니다.
- 누락 입력, 잘못된 응답, Gemini 실패 시 오류를 확인합니다.
- 프롬프트와 결과에 출생일·출생시간 원문이 포함되지 않는지 확인합니다.

검증 결과: 미실행
