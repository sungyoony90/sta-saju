# 003 Google 로그인

## 상태

- 작성일: 2026-09-23
- 구현 및 기본 사용자 흐름 검증 완료

## 목적

사용자가 자신의 Google 계정으로 로그인하고, 로그인 상태에서만 본인의 저장된 사주 해석을 볼 수 있게 합니다.

## 현재 프로젝트 확인

- Supabase 프로젝트 `lswmyltwdwvahbsvkefv`의 Google 인증 제공자가 켜져 있습니다.
- Supabase 인증 URL 설정에 `http://localhost:3000`과 `http://localhost:3000/**`가 있습니다.
- 로컬 `.env`에 프로젝트 URL과 공개용 API 키가 설정돼 있습니다. 값 자체는 문서에 기록하지 않습니다.

## 사용자 흐름

1. 첫 화면에서 `Google로 로그인`을 누릅니다.
2. Supabase가 Google 인증 화면으로 보냅니다.
3. 인증 뒤 원래 서비스 화면으로 돌아와 로그인 상태와 계정 정보를 보여줍니다.
4. `로그아웃`을 누르면 세션을 끝내고 화면의 개인 상담 결과를 지웁니다.
5. 로그인 취소·실패 시 서비스 화면으로 돌아와 다시 시도할 수 있습니다.

## 구현 결정

- 기존 Next.js/React 화면에서 Supabase 공식 JavaScript 클라이언트를 사용합니다.
- 브라우저에서 `signInWithOAuth({ provider: "google" })`로 로그인합니다.
- 클라이언트 ID·시크릿 및 관리자 비밀키를 브라우저 코드나 Git에 넣지 않습니다.
- 브라우저에는 공개용 Supabase 연결값만 노출합니다.
- 로그인 상태는 Supabase 인증 세션으로 확인하며, 화면의 계정 이름만 보고 저장 권한을 판단하지 않습니다.
- 이번 구현에서는 로그인 없이 해석할 수 있고, 계정 저장만 로그인이 필요합니다. 사용하면서 조정할 수 있습니다.

## 오류와 보안

- 연결 설정이 없으면 로그인 버튼 대신 설정 안내를 보여줍니다.
- 인증 취소·실패 시 비밀값 또는 내부 오류 전문을 표시하지 않습니다.
- 로그아웃 뒤 현재 화면의 계산 결과·해석·대화를 초기화합니다.
- 결과 데이터 접근은 Google 이메일이 아니라 Supabase 인증 사용자 ID와 데이터베이스 행 수준 보안(RLS)으로 제한합니다.

## 완료 조건

- 로그인 버튼이 실제 Google 인증 절차를 시작합니다.
- 돌아온 화면에서 로그인 상태가 반영됩니다.
- 로그아웃 후 계정 정보와 개인 결과가 보이지 않습니다.
- 인증 없는 사용자는 저장된 결과를 조회하거나 저장할 수 없습니다.
- 타입 검사, 관련 자동 테스트, 브라우저 확인이 통과합니다.

## 검증 결과

- Supabase의 Google 인증 제공자와 로컬 복귀 URL 설정을 확인했습니다.
- 실제 Google 로그인 완료 후 서비스 화면에서 계정 상태가 반영되는 것을 확인했습니다.
- 타입 검사, 자동 테스트 36개, 배포용 빌드가 통과했습니다.
- 로그아웃 시 화면을 초기화하는 코드를 확인했습니다. 실제 로그아웃 화면 조작은 사용자의 로그인 세션을 유지하기 위해 수행하지 않았습니다.
