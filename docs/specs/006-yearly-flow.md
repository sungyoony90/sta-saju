# 006 — 올해와 선택 연도의 흐름

상태: 구현 전

## 목적

현재 시점 이후의 흐름을 기본으로 보되, 사용자가 다른 미래 연도 한 개를 고를 수 있게 합니다.

## 동작

- 접속일은 한국 표준시 기준으로 구하고 올해를 기본값으로 둡니다.
- 이번 단계의 선택 범위는 올해부터 5년 뒤까지입니다. 과거 연도는 거절합니다.
- 올해 결과는 `오늘 이후의 흐름`이라고 표시하되 월별·날짜별 세부 계산이 없는 만큼 특정 날짜에 사건이 일어난다고 말하지 않습니다.
- 대상 연도의 간지와 연도 경계 기준을 계산 모듈에 명시합니다. 절기 기준이 필요한 경우 입춘 전후 사례를 테스트합니다.
- 결과는 대상 연도, 전체 방향, 관계·일·돈의 세 영역과 근거·현실 점검 항목을 포함합니다.
- 연도를 변경하면 이전 연도의 풀이가 새 연도 풀이처럼 보이지 않도록 초기화합니다.
- 로그인 사용자의 저장 기록에는 대상 연도를 구분 가능하게 남기며 이전 기록은 유지합니다.

## 검증

- 올해, 1년 뒤, 5년 뒤, 범위 밖 연도와 입춘 경계 사례를 테스트합니다.
- 계산 오류 및 Gemini 실패에서 가짜 결과가 나타나지 않는지 확인합니다.
- 저장 후 다시 열었을 때 같은 연도가 보이는지 확인합니다.

검증 결과: 미실행
