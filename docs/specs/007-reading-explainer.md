# 007 — 풀이 근거와 용어 설명

상태: 구현 및 검증 완료

## 목적

사용자가 풀이를 맹신하지 않고 계산값과 설명의 관계를 스스로 살펴볼 수 있게 합니다.

## 동작

- 네 기둥, 일간, 목·화·토·금·수의 대표 오행 8자 개수를 화면에 표시합니다.
- 그래프나 막대는 개수를 정직하게 표시하고, 개수만으로 오행의 강약·길흉을 결론 내리지 않습니다.
- `년주`, `월주`, `일주`, `시주`, `일간`, `오행`의 뜻을 쉬운 말로 설명합니다.
- 각 해석 카드에서 `왜 이렇게 읽었나요?`를 펼쳐 근거를 볼 수 있습니다.
- 근거에는 입력된 계산값과 관련 없는 사주 요소나 검증되지 않은 경험을 넣지 않습니다.
- 키보드로 펼치고 닫을 수 있으며 작은 화면에서도 읽을 수 있습니다.

## 검증

- 오행 개수 합계가 8이고 화면 표기가 계산값과 일치하는지 확인합니다.
- 용어 풀이와 근거 펼치기가 키보드·모바일 화면에서 동작하는지 확인합니다.
- AI가 내놓은 근거가 계산값을 벗어나면 결과를 사용하지 않는 보호 장치를 확인합니다.

검증 결과 (2026-09-28):

- 네 기둥, 일간, 대표 오행 8자와 합계를 화면에 표시하고 강약 판단값이 아니라는 안내를 함께 표시함.
- 년주·월주·일주·시주·일간·오행의 쉬운 설명을 기본 `details/summary`로 제공해 키보드 조작을 지원함.
- 모든 풀이 카드에 `왜 이렇게 읽었나요?`와 허용된 계산 근거 문자열을 표시함.
- 계산 결과에 없는 근거 참조를 응답 검사에서 거절하는 테스트를 추가함.
- 390px 모바일 뷰에서 가로 넘침이 없고 탭·연도 선택이 표시됨을 실제 화면에서 확인함.
- TypeScript 검사, 전체 자동화 테스트 49개, Next.js 프로덕션 빌드 통과.
