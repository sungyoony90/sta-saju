# 009 — 오전 9시 Slack 오늘의 운세 알림

상태: 구현 중

## 목적

사용자가 매일 한국 시간 오전 9시대에 Slack 봇 알림을 받고, 링크를 눌러 로그인한 뒤 오늘의 운세를 확인할 수 있게 합니다.

## 동작

- Vercel Cron이 매일 `00:00 UTC`에 보호된 서버 경로를 호출합니다. 이는 한국 시간 오전 9시에 해당합니다.
- Hobby 플랜에서는 Vercel의 시간 정밀도 제한으로 오전 9시부터 9시 59분 사이에 실행될 수 있습니다. 정확한 9시 실행은 Pro 플랜이 필요합니다.
- 서버는 `SLACK_BOT_TOKEN`으로 Slack Web API `chat.postMessage`를 호출합니다.
- 전송 대상은 `SLACK_CHANNEL_ID`로 지정합니다. 채널 ID 또는 본인의 Slack 사용자 ID를 사용할 수 있습니다.
- 메시지는 `오늘의 운세를 확인해보세요!` 안내와 `APP_URL` 링크를 포함합니다.
- Slack에는 생년월일, 출생시간, 원국, 운세 내용, 이메일과 같은 개인정보를 보내지 않습니다.
- 사용자는 링크에서 Google 로그인 후 오늘의 운세를 직접 생성합니다.

## 보안과 실패 처리

- Cron 경로는 `CRON_SECRET`과 `Authorization: Bearer ...`가 일치할 때만 실행합니다.
- `CRON_SECRET`은 16자 이상의 임의 문자열을 사용합니다.
- 봇 토큰, Cron 비밀값과 Slack 대상 ID를 코드·Git·응답·로그에 출력하지 않습니다.
- 환경변수 누락은 `503`, 인증 실패는 `401`, Slack 전송 실패는 `502`로 구분하고 성공으로 위장하지 않습니다.
- Slack 봇에는 `chat:write` 권한만 우선 부여합니다. 공개 채널 전체 전송 권한은 이번 범위에서 요청하지 않습니다.

## 환경변수

- `SLACK_BOT_TOKEN`: Slack 앱 설치 후 받은 `xoxb-` 봇 토큰
- `SLACK_CHANNEL_ID`: 알림을 받을 채널 ID 또는 본인의 사용자 ID
- `CRON_SECRET`: Vercel Cron 요청 검증용 16자 이상 비밀값
- `APP_URL`: 알림에서 열 오늘의 운세 사이트 HTTPS 주소

## 이번 범위에서 제외

- 사용자별 알림 시간 설정
- 여러 Slack 워크스페이스에 대한 OAuth 설치 화면
- Slack 안에서 생년월일을 받거나 운세 내용을 직접 생성하는 기능
- 실패한 알림의 자동 재시도와 중복 전송 저장소

## 검증

- 올바른 Cron 인증만 Slack 호출을 수행하는지 확인합니다.
- 환경변수 누락과 Slack 오류를 구분하는지 확인합니다.
- Slack 요청이 봇 토큰 인증, 대상 ID, 고정 안내 문구와 `APP_URL`만 포함하는지 확인합니다.
- 메시지와 서버 응답에 비밀값·개인정보가 포함되지 않는지 확인합니다.
- Vercel 설정의 경로와 `0 0 * * *` 일정이 일치하는지 확인합니다.
- 관련 Test, TypeScript 검사, 프로덕션 빌드와 실제 Slack 전송을 확인합니다.

검증 결과 (2026-09-28):

- 구현을 맡지 않은 테스트 에이전트가 Cron 인증, 설정 누락, Slack 요청 payload, 비밀값·개인정보 비노출, Slack·네트워크 실패, Vercel 일정 검증을 포함한 Test 6개를 추가했습니다.
- 전체 자동 Test 63개가 통과했습니다.
- TypeScript 검사와 프로덕션 빌드가 통과했으며 `/api/cron/daily-fortune-reminder` 동적 경로가 생성되는 것을 확인했습니다.
- 실제 Slack 앱 설치, Vercel 환경변수 연결과 메시지 수신은 아직 `NOT TESTED`이며 완료 전까지 이 Spec과 상태 체크박스를 완료로 변경하지 않습니다.
