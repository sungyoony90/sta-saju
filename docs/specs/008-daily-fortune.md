# 008 — 오늘의 운세

상태: 구현 및 검증 완료

## 목적

출생 원국과 한국 시간의 오늘 일진을 함께 사용해, 사용자가 매일 확인할 수 있는 짧고 현실적인 운세를 제공합니다. 매일 자동 발송은 이 Spec의 범위에 포함하지 않습니다.

## 동작

- 출생 정보 입력 후 `오늘의 운세 보기`를 누르면 결과를 생성합니다.
- 오늘 날짜는 서버에서 `Asia/Seoul` 기준으로 정하며 클라이언트가 임의로 보낸 날짜를 사용하지 않습니다.
- 오늘 일진은 `lunar-javascript`와 `lib/saju`가 계산하고 Gemini에게 계산을 맡기지 않습니다.
- Gemini에는 생년월일·출생시간 원문을 보내지 않고, 검증된 원국 계산값·오늘 날짜·오늘 일진만 전달합니다.
- 결과는 한 줄 요약과 `전체 흐름`, `일과 돈`, `관계` 카드로 구성합니다. 각 카드에는 풀이, 계산 근거, 오늘 할 수 있는 행동을 포함합니다.
- 미래의 사건·수익·행운을 보장하지 않으며 중요한 결정은 현실 조건을 확인하도록 안내합니다.
- Gemini 실패, 시간 초과, JSON 형식 오류는 가짜 운세로 대체하지 않고 오류와 재시도를 표시합니다.
- 같은 화면의 기존 커리어 상담·로그인·저장 기록은 유지합니다.

## 이번 범위에서 제외

- 이메일·메신저·푸시를 통한 매일 자동 발송
- 날짜 선택, 과거·미래 일자 운세
- 오늘의 운세 저장과 알림 시간 설정

## 검증

- 한국 시간 날짜가 UTC 날짜와 다른 경계 시각에도 올바른 날짜를 선택하는지 확인합니다.
- 고정 날짜의 일진 계산값이 재실행해도 동일한지 확인합니다.
- 정상 Gemini JSON만 표시하고 카드 누락·중복·과도한 필드를 거절하는지 확인합니다.
- 프롬프트에 출생일·출생시간 원문이 포함되지 않는지 확인합니다.
- 기존 전체 Test, TypeScript 검사, 프로덕션 빌드를 실행합니다.

검증 결과 (2026-09-28):

- 별도 테스트 작성 에이전트가 오늘 날짜 경계, 고정 일진, Gemini 응답 계약, 출생 원문 제외, 서버 날짜 강제를 포함한 7개 Test를 추가했습니다.
- 전체 자동 Test 43개가 통과했습니다.
- TypeScript 검사와 프로덕션 빌드가 통과했습니다.
- 로컬 실제 화면에서 출생 정보 입력 → 원국 계산 → 실제 Gemini 오늘의 운세 생성 흐름을 확인했습니다.
- 2026년 9월 28일 한국 날짜와 `乙巳(을사)` 일진, 한 줄 요약, 전체·일과 재물·대인관계 카드, 근거 펼치기, 주의점이 표시되는 것을 확인했습니다.
- Gemini 연결 실패 시 오류 안내가 표시되고 가짜 결과가 남지 않는 것을 확인했습니다.
