# 001 맞춤 사주 커리어 상담 프로토타입

## 목적

Gemini API 키가 없는 상태에서도 사용자가 맞춤 상담의 전체 흐름을 직접 체험하고 평가할 수 있게 합니다.

## 범위

- 기존 양력 생년월일·출생시간 입력과 사주 계산을 유지합니다.
- 현재 상태, 고민, 변화 시점을 선택하고 현재 상황과 질문을 입력합니다.
- 계산 결과와 상황 입력을 반영한 샘플 요약 카드 3개를 표시합니다.
- 각 카드에서 `자세히 보기`로 사주 근거를 확인합니다.
- 후속 질문은 최대 3회이며 샘플 규칙 답변을 표시합니다.
- 새로고침 후 상담 내용은 남지 않습니다.

## 제외

- Gemini 실제 호출
- 로그인, 저장, 결제, 공유
- 음력과 출생시간 모름 처리

## 완료 조건

- 필수 입력 누락 시 구체적인 안내가 표시됩니다.
- 정상 입력 시 직업·이직 방향, 핵심 성향, 가까운 흐름 카드가 나타납니다.
- 카드에 쉬운 요약과 펼칠 수 있는 근거가 함께 있습니다.
- 후속 질문을 세 번 보낸 뒤 추가 입력이 비활성화됩니다.
- 재정 보장을 요구하는 질문에는 보장하지 않는다는 안내와 현실 조건이 포함됩니다.
- `npm run check`에 해당하는 타입 검사와 Test가 모두 통과합니다.
- 브라우저에서 핵심 흐름을 직접 확인합니다.

## Eval 기준

1. 계산된 일간·오행과 사용자의 선택·자유 입력이 답변에 드러납니다.
2. 결론은 분명하지만 미래나 수익을 확정하지 않습니다.
3. 근거와 현실에서 확인할 다음 행동이 함께 표시됩니다.
4. 후속 답변은 같은 상담 맥락을 유지합니다.

## 검증 결과

- 2026-09-23 타입 검사 통과: `tsc --noEmit`
- 자동 Test 24개 통과: 기존 사주 계산 16개 + 프로토타입 8개
- 브라우저 확인 완료:
  - 사주 계산 뒤 현재 상황 입력 화면 표시
  - 요약 카드 3개와 `자세히 보기` 근거 표시
  - 재정 보장 질문에 보장 거절·손실 가능성·현실 조건 안내
  - 후속 질문 3회 뒤 입력 종료 안내
  - 브라우저 콘솔 오류 없음
- Gemini API 키가 없어 실제 AI 호출은 이번 Spec 범위에서 제외하고 샘플 규칙으로 검증했습니다.
