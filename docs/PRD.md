# 📋 기획서 (PRD) : 맞춤 사주 커리어 상담 (가칭)

> 사주를 자주 보는 사용자가 뻔한 풀이에서 벗어나, 자신의 사주와 현재 상황을 함께 반영한 직업·재물 상담을 받을 수 있는 웹서비스입니다.
> 이 문서는 현재 합의한 기준이며, 실제로 사용하고 검증하면서 계속 수정합니다.

작성일: 2026-09-23  
작성자: 참가자

---

## 1. 풀고자 하는 문제

- **현재 방식:** 사주 서비스에 생년월일과 출생시간을 입력하고 정해진 풀이를 읽습니다.
- **문제점:** 풀이가 누구에게나 비슷하고 뻔해서 내 사주와 현재 고민을 구체적으로 반영했다는 느낌이 부족합니다.
- **이상적인 모습:** 계산된 사주와 현재 상황을 함께 반영해 직업·이직·진로와 돈·재물에 대한 분명한 방향을 제안하고, 이어지는 질문에도 앞선 맥락을 유지해 답합니다.

## 2. 사용자

- **누가 쓰나요?** 사주를 자주 보고 자세한 풀이를 원하는 사람
- **언제 쓰나요?** 직업·이직·진로 또는 돈·재물에 관한 고민을 정리하고 싶을 때
- **어디서 쓰나요?** 컴퓨터나 휴대전화의 웹브라우저
- **핵심 가치:** “일반적인 문구가 아니라 내 사주와 현재 상황을 반영한 답변이다”라는 확신

## 3. 입력 자료와 개인정보

- **기본 입력:** 양력 생년월일, 출생시간
- **상황 선택:** 현재 직업 상태, 가장 큰 고민, 원하는 변화 시점
- **자유 입력:** 현재 상황 설명과 구체적인 질문
- **필수 항목:** 양력 생년월일, 출생시간, 현재 상황, 질문
- **처리 원칙:**
  - 생년월일과 출생시간은 서비스 내부의 사주 계산에만 사용합니다.
  - Gemini에는 생년월일과 출생시간 자체를 보내지 않습니다.
  - Gemini에는 계산된 사주 결과, 현재 상황과 질문만 전달합니다.
  - Google로 로그인한 경우 계산된 사주와 검증된 해석 결과만 Supabase 데이터베이스에 저장합니다.
  - 생년월일·출생시간 원문, 현재 상황·질문·후속 대화 원문은 저장하지 않습니다.
  - 본인 계정의 기록만 볼 수 있도록 데이터베이스 접근 규칙을 적용합니다.
- **준비된 자료:** Gemini API 키는 서버 설정에만 보관합니다. Google 로그인에는 Supabase의 공개용 연결 설정을 사용합니다.

## 4. 핵심 기능 (MVP)

1. 양력 생년월일과 출생시간으로 기존 계산 기능이 사주 원국을 계산합니다.
2. **직업·이직 방향**, **핵심 성향**, **현재 또는 가까운 시기의 흐름**을 쉬운 요약 카드로 보여줍니다.
3. 각 카드의 `자세히 보기`에서 해석에 사용한 사주 요소와 전문 용어의 쉬운 설명을 보여줍니다.
4. 선택 질문에 답한 뒤 현재 상황과 고민을 자유롭게 작성할 수 있습니다.
5. 기본 풀이 이후 최대 3회의 추가 질문을 할 수 있고, 답변은 앞선 사주 결과와 대화 맥락을 유지합니다.

- **사주 계산 기능:** 원국과 해석에 필요한 기초 데이터를 일관되게 계산
- **AI:** 계산 결과와 현재 상황을 연결한 기본 풀이 및 후속 답변 작성
- **사람:** 답변을 참고하되 실제 이직·투자·재정 결정은 현실 조건을 확인해 직접 판단

## 5. 핵심 사용자 흐름

1. 양력 생년월일과 출생시간을 입력합니다.
2. 서비스가 사주를 계산합니다.
3. 현재 직업 상태, 가장 큰 고민, 원하는 변화 시점을 선택합니다.
4. 현재 상황과 질문을 자유롭게 작성합니다.
5. 세 가지 쉬운 요약 카드를 확인합니다.
6. `자세히 보기`에서 카드별 사주 근거를 확인합니다.
7. 최대 3회의 후속 질문을 이어갑니다.
8. Google 로그인 사용자는 최근 저장된 해석을 다시 열거나 삭제할 수 있습니다. 로그인 전 해석은 계정에 자동 저장되지 않습니다.

## 6. 답변 원칙과 평가 기준

- **말투:** 전문적인 근거를 사용하되 쉬운 말과 현실적인 제안으로 설명하는 혼합형
- **표시:** 쉬운 요약을 먼저 보여주고 `자세히 보기`에서 전문 근거 제공
- **결론:** 추천 방향은 분명하게 말하되 미래를 사실처럼 확정하지 않음
- **구조:** 한 줄 결론 → 현재 상황을 반영한 해석 → 사주 근거 → 현실에서 확인할 조건 → 다음 행동
- **최우선 기준:** 사주 요소와 사용자의 현재 상황이 답변에 구체적으로 반영되어야 함
- **기본 조건:**
  - 전문 용어에는 쉬운 설명을 붙입니다.
  - 후속 답변은 이전 답변과 모순되지 않습니다.
  - 이직·투자·재정 결과를 보장하거나 특정 결정을 강요하지 않습니다.
  - 현실에서 확인할 조건과 다음 행동을 함께 제시합니다.

답변 예시:

> 지금은 바로 퇴사하기보다 이직 준비를 시작하는 쪽을 추천합니다. 사주에서는 변화 욕구가 강해지는 흐름으로 해석되지만, 실제 결정 전에는 준비 자금과 채용 상황을 함께 확인하세요.

## 7. 결과와 완료 조건

- **결과물:** `day09`의 Next.js 웹 화면에 입력, 기본 풀이, 자세한 근거, 후속 질문 대화를 표시
- **정상:** 유효한 입력이면 세 가지 카드와 근거가 나타나고, 최대 3회의 후속 질문에 맥락을 유지한 답변이 표시됨
- **누락:** 필수 입력이 없거나 잘못되면 확인해야 할 항목을 쉬운 문장으로 안내함
- **AI 실패:** 실패를 가짜 풀이로 바꾸지 않고 다시 시도하라는 안내를 표시함
- **저장:** 로그인 사용자는 새로고침 후 계정에 저장된 결과를 다시 열 수 있고, 깨진 저장 데이터는 안전하게 무시해야 함
- **품질:** 서로 다른 사주와 상황을 넣었을 때 근거와 제안이 구체적으로 달라야 함

7. Google 로그인과 계정별 데이터베이스 저장·복원 연결 (`003`, `004` Spec)
