# 기획서 (PRD): 내 사주 전체와 앞으로의 흐름

> 출생 정보 하나로 변하지 않는 사주의 바탕과 선택한 미래 연도의 흐름을 나누어 보고, 풀이의 계산 근거를 이해할 수 있는 서비스입니다. v01을 보존한 채 2026-09-23 대화를 반영한 통합 실험안입니다.

작성일: 2026-09-23  
작성자: 참가자

## 1. 풀고자 하는 문제

- **현재 방식:** 취업 상태와 이직 고민을 입력해야 사주 풀이를 볼 수 있습니다.
- **문제점:** 특정 개인의 취업 고민을 전제하여 일반 사용자의 삶 전반을 보기 어렵고, AI 풀이와 실제 계산값의 관계도 드러나지 않습니다.
- **원하는 모습:** `내 사주 전체`에서 평생의 기본 성향을, `앞으로의 흐름`에서 올해 남은 기간 또는 선택한 미래 연도를 살펴보고, 어려운 용어와 근거를 필요할 때 펼쳐봅니다.

## 2. 사용자

- **누가 쓰나요?** 취업 여부와 무관하게 자기 사주와 미래 흐름이 궁금한 사람.
- **언제 쓰나요?** 자신의 경향을 이해하거나 올해·미래 한 해를 살펴볼 때.
- **어디서 쓰나요?** 컴퓨터·휴대전화의 웹브라우저.

## 3. 입력 자료

- **필수:** 양력 생년월일·출생 시각. 현재 계산 지원 범위(1990년 이후, 시각을 아는 경우)를 우선 유지합니다.
- **선택:** 미래 연도 한 개. 기본값은 접속일의 연도이며 올해는 접속일 이후만 풀이 대상으로 표시합니다.
- **개인정보:** 생년월일·출생 시각 원문은 브라우저에서 계산할 때만 쓰고 Gemini나 계정 저장소에 보내지 않습니다. 계정 저장은 계산값·풀이·대상 연도만 대상으로 하며 기존 기록은 계속 열 수 있어야 합니다. API 키는 서버에만 둡니다.

## 4. 핵심 기능 (MVP)

1. 같은 출생 정보로 두 메뉴를 사용합니다. `내 사주 전체`는 성향·강점·관계·일·돈의 반복 경향을 다루고 특정 사건을 단정하지 않습니다.
2. `앞으로의 흐름`은 올해 남은 기간을 기본으로, 사용자가 미래 연도 한 개를 선택해 전체 방향과 관계·일·돈의 가능성과 점검할 조건을 봅니다. 과거 생애를 길게 예언하지 않습니다.
3. 계산된 네 기둥과 오행의 대표 개수, 용어 뜻, 카드별 계산 근거를 사용자가 펼쳐 이해할 수 있게 합니다. 오행 개수만으로 강약을 단정하지 않습니다.
4. Gemini는 계산된 값을 쉬운 말로 해석하며 계산·사건·수익을 지어내지 않습니다. 실패하면 오류와 재시도를 표시합니다.
5. Google 로그인 사용자는 새 형식의 결과를 저장·다시 열기·삭제할 수 있고, 이전 취업 풀이 기록도 잃지 않습니다.

- **계산이 할 일:** 출생 원국과 대상 연도의 간지를 검증 가능한 기준으로 산출.
- **AI가 할 일:** 제공받은 계산값만 설명하고 현실에서 확인할 조건 제시.
- **사람이 할 일:** 중요한 관계·직업·금전 결정은 현실 정보와 함께 판단.

## 5. 결과와 완료 조건

- **결과물:** 독립 Git 워크트리의 실행 가능한 통합 웹 화면. 기존 `day09` 화면과 비교한 뒤 원본에 반영 여부를 결정합니다.
- **정상:** 출생 정보 입력 후 두 메뉴를 오가고, 전체 풀이 및 선택 연도 풀이·계산 근거를 볼 수 있습니다. 현재 연도에는 `오늘 이후` 안내가, 미래 연도에는 그 연도가 표시됩니다.
- **오류:** 입력·연도·Gemini·저장 오류를 구별하여 알리고 만들어낸 결과로 대체하지 않습니다.
- **보존:** 기존 계정 기록, 로그인, 비밀키, 원본 폴더가 유지됩니다. 저장 기록마다 전체/연도/기존 풀이를 구분할 수 있습니다.
